# Standalone repository

MoonWitness is maintained at https://github.com/huahai29/moonwitness.

The original project lived under `moonwitness/` in the personal-site repository
`huahai29/lunli-home`. Its two project commits were extracted with Git subtree
history preservation. The full project README is at the repository root; the
MoonBit module is in `moon/` and the browser host is in its sibling `web/`.

The standalone repository owns source, tests, licensing, releases and CI. The
personal-site repository links here and keeps a static compatibility copy of the
browser demo for existing `/lunli-home/moonwitness/web/` links. That copy is not a
second source repository; future source changes should be made here.

The canonical demo is https://huahai29.github.io/moonwitness/.
